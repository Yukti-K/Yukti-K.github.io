How to add your photos

Upload image files to images/hiking/ or images/crochet/ on GitHub, then add a line with each filename and caption to gallery.js. Commit both changes to publish the photos. This site runs on GitHub Pages, so an on-page upload cannot permanently save photos without an external storage service.
